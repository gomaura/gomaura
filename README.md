
**Offensive Security Engineer | Cloud, Identity & Application Security**

I specialize in full-scope penetration testing and adversarial simulation across modern enterprise environments—spanning **Cloud Infrastructure (AWS, Azure/Entra ID, GCP)**, **Active Directory**, **Web/API/Mobile applications**, and **AI/LLM integrations**.

**Philosophy & Approach**
* **Fundamentals Over Automation:** I focus on understanding underlying protocols, identity mechanics, and business logic rather than relying on automated vulnerability scanners.
* **Identity-First Exploitation:** Modern breaches happen through misconfigured permissions, OAuth/OIDC flaws, IAM role chaining, and Active Directory delegation abuse.
* **Actionable Impact:** Finding a bug is only half the job; every assessment ends with clear risk ratings, proof-of-concept evidence, and practical remediation.


**Core Capabilities**
* **Cloud & Containers:** AWS (IAM, STS, IMDS, S3, Lambda), Azure/Entra ID (App Registrations, Consent Abuse, Conditional Access), GCP, Kubernetes & CI/CD pipelines.
* **Internal & Active Directory:** BloodHound pathing, Kerberoasting, NTLM relay/coercion, ADCS abuse, lateral movement, and OPSEC-conscious post-exploitation.
* **Web, API & Mobile:** IDOR/BOLA, OAuth/SAML/JWT attacks, SSRF, deserialization, request smuggling, GraphQL/gRPC testing, and Android/iOS dynamic analysis (Frida).
* **AI & LLM Security:** Prompt injection, insecure tool/agent execution, and sensitive data exfiltration.
